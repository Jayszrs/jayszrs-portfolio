# Next.js 16 and interface refinement — 21 October 2026

Changes are local. No deployment, git push, Blob mutation, Supabase write, credential change, or original media deletion was performed.

## Implementation

- Next.js 16.4.2, React/React DOM 19.3.1, and `@vercel/analytics` 2.0.1. The official Next.js Analytics component is mounted in the root layout. Dashboard enablement and production event collection remain unverified.
- Migrated route-level `revalidate` exports to literal app-route configuration and used `revalidateTag(tag, { expire: 0 })` so an authorized CMS save can invalidate content immediately. Replaced the removed `next lint` command with an explicit build check; this does not claim an ESLint pass.
- Removed Framer Motion, whose only consumer was the lanyard. The badge now uses CSS perspective, metal/plastic depth, and bounded pointer movement. Recovered photos advance every 3 seconds, with previous/next/pause controls. Automatic changes pause offscreen, on hover/focus, in hidden tabs, and for reduced-motion preferences.
- Deferred social code and profile requests until the section approaches the viewport. Main navigation no longer automatically prefetches every public route. Only one visible TikTok player is mounted at a time.
- Next Image now sizes local JPEG/PNG assets instead of serving all recovered originals at card size. SVG and existing WebP files retain direct delivery. Known inaccessible legacy images fail locally; source URLs remain preserved and new recovery aliases take precedence.
- Losslessly compressed the local variable font from 176,288 to 60,424 bytes in WOFF2 format. Glyph mapping and glyph order were checked; original TTF and OFL license remain intact.
- Refined the mobile menu, animated hamburger, Escape/outside dismissal, larger tablet breakpoint, and scroll-dependent navbar width/floating control scale. Reduced motion disables decorative transitions.
- PPJI and KIK have separate transparent symbol display variants made with imagegen; original rasters are untouched. Akademi Crypto has a lightweight SVG display interpretation based on the preserved original. These are display variants, not newly recovered original files. Organization symbols receive restrained CSS depth.
- Certificate logos have independent accessible preview buttons, separate from the certificate/detail action. Instagram embeds use a width-dependent frame to reduce unused vertical space; profile music remains the configured track.
- Japanese and French each contain 788 complete public-content translations, loaded only when selected. Removed partial-word paragraph translation, fixed mutation-induced cancellation, guarded stale language responses, deduplicated fallback requests, split long paragraphs, and allowed retry after network failure. Current catalogs cover all long text fields in the audited public CMS snapshot. Future content uses the existing network translation fallback. Fifty-two French texts were completed locally after the remote service became unavailable; review evidence is retained in `backups/fr-content-review-2026-10-21-*` at repository root.

## Outstanding evidence and source limitations

- Browser connection inventory was empty. No rendered desktop/mobile, actual click, autoplay, scroll, or cross-origin embed appearance pass is claimed. HTTP and unit tests do not replace that review.
- The TikTok layout accepts up to three real video cards and ranks by views when authorized API data is available. Only one owner post URL is currently verified; it is shown as a curated selection without invented view counts. Two more posts and a verified popularity ranking are still unavailable.
- Sixty-eight original image URLs remain inaccessible. Their references and archives are preserved; this change does not claim to have recovered those photographs.
- Instagram profile embed internals and their language remain controlled by Instagram. Account Story/Notes updates are not synchronized from a private-account API.
